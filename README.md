# AI Email Client

A modern, intelligent email client built with Next.js, featuring AI-powered email composition, smart replies, and calendar integration.

## Features

- 🤖 **AI-Powered Email Composition** - Generate professional emails using AI
- 📧 **Smart Email Management** - Organize, search, and manage emails efficiently  
- 📅 **Calendar Integration** - Schedule meetings directly from emails
- 🔍 **Advanced Search** - Find emails quickly with intelligent search
- 🎨 **Modern UI** - Clean, responsive interface with dark/light themes
- 🔐 **Secure Authentication** - Powered by Clerk authentication
- 📱 **Mobile Responsive** - Works seamlessly on all devices

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: Clerk
- **AI Services**: Google Gemini, OpenAI
- **Email**: Resend, Gmail IMAP
- **UI**: Tailwind CSS, Radix UI
- **TypeScript**: Full type safety

## Prerequisites

- Node.js 18+ 
- PostgreSQL database
- API keys for AI services (see Environment Variables)


## Usage

### Email Management
- View and organize emails in a clean interface
- Search emails with advanced filters
- Archive, delete, and star important emails

### AI Features
- **Smart Compose**: Generate emails using AI
- **Quick Replies**: AI-suggested responses
- **Email Summarization**: Get quick summaries of long emails
- **Tone Analysis**: Understand email sentiment

### Calendar Integration
- Schedule meetings directly from emails
- Export to Google Calendar, Outlook, or .ics files
- Set reminders and notifications
